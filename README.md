## Installation


### Dependencies

- Chrono:
  - repo: https://github.com/projectchrono/chrono
  - version: 7.0.3

- json:
  - repo: https://github.com/nlohmann/json
  - version: 3.10.5

  
### Compilation

From a directory `./build`:
```
cmake .. -DChrono_DIR=/path/to/your/chrono/cmake/build/directory
make
```
